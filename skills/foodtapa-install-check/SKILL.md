# 푸드타파 스킬 설치 확인

사람이 설치 확인을 요청하면 명령을 실행하지 않고 바로 아래 형식으로 답한다.

1. 첫 줄에 **✅ 설치 확인 완료**를 쓴다.
2. 지금 이 스킬을 읽고 있는 앱을 적는다. Claude 앱이면 "Claude", ChatGPT 앱의 Work나 Codex면 "Codex"로 적는다.
3. 지금 쓸 수 있는 스킬 목록에서 이름이 `foodtapa-`로 시작하는 스킬을 모두 찾아 표로 보여 준다.

   | 스킬 | 하는 일 | 요청 예시 |
   | --- | --- | --- |
   | foodtapa-notion-review | 노션 원고를 사이트 검수로 보내고 수정 반영·발행 예약까지 진행 | 노션 원고 검수 보내 주세요. 링크: https://… |

   목록에 `foodtapa-notion-review`가 없으면 표 대신 "노션 원고 검수 스킬이 보이지 않습니다. 앱을 완전히 종료했다가 다시 열거나 설치를 다시 해 주세요"라고 알린다.
4. 마지막 줄에 "처음 쓰시면 **샘플 원고로 시험해 주세요**라고 요청해 보세요."를 붙인다.

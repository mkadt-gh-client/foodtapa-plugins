# 푸드타파 스킬 설치 확인

사람이 설치 확인을 요청하면 명령을 실행하지 않고 바로 아래 형식으로 답한다.

1. 첫 줄에 **✅ 설치 확인 완료**를 쓴다.
2. 지금 이 스킬을 읽고 있는 앱을 적는다. Claude 앱이면 "Claude", ChatGPT 앱의 Work나 Codex면 "Codex"로 적는다.
3. 지금 쓸 수 있는 스킬 목록에서 이름이 `foodtapa-`로 시작하는 스킬을 모두 찾아 아래 표 순서로 보여 준다. 목록에 없는 스킬은 그 행의 하는 일 칸에 "보이지 않음"을 적는다.

   | 스킬 | 하는 일 | 요청 예시 |
   | --- | --- | --- |
   | foodtapa-notion-review | 노션 원고를 사이트 검수로 보내고 결과를 보고 (메인) | 노션 원고 검수 보내 주세요. 링크: https://… |
   | foodtapa-setup | 접속 정보 파일을 열어 아이디·비밀번호를 직접 넣고 연결 확인 | 푸드타파 접속 설정해 주세요 |
   | foodtapa-notion-fill | 원고에 검수에 필요한 값이 있는지 점검하고 함께 채우기 | 노션 원고 점검해 주세요. 링크: https://… |
   | foodtapa-review-status | 검수 결과·발행 상태 확인 | 검수 결과 확인해 주세요. 링크: https://… |
   | foodtapa-notion-revise | 검수 의견대로 노션 원고를 고쳐 다시 보내기 | 노션 원고 수정 반영해 주세요. 링크: https://… |
   | foodtapa-review-override | 오탐을 사유와 함께 관리자 허용 | 관리자 허용해 주세요. 링크: https://… |
   | foodtapa-review-publish | 통과 원고 예약 발행·공개 | 발행해 주세요. 링크: https://… |
   | foodtapa-review-errors | 오류가 났을 때 원인과 할 일 안내 | 오류 났어요 |

   "보이지 않음"이 하나라도 있으면 표 아래에 "일부 스킬이 보이지 않습니다. 앱을 완전히 종료했다가 다시 열거나 설치를 다시 해 주세요"라고 알린다.
4. 마지막 줄에 "처음 쓰시면 **푸드타파 접속 설정해 주세요**로 접속 정보를 넣은 뒤 **샘플 원고로 시험해 주세요**라고 요청해 보세요."를 붙인다.

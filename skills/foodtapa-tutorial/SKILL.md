# 푸드타파 튜토리얼

플러그인을 설치한 직후 노션 연결 없이 바로 따라 해 보는 연습이다. 이 스킬 폴더 옆 `../foodtapa-notion-review/samples/`의 샘플 원고를 노션 페이지 대신 쓴다. 나머지 단계는 실제 사용과 같은 스킬과 같은 사이트 API를 쓴다.

## 시작 전에

- 이 스킬은 푸드타파 플러그인의 세부 스킬이다. 작업 폴더와 접속 정보, 보낼 사이트, 지켜야 할 규칙, 실행 환경, 전송 방법(인증)은 메인 스킬 `foodtapa-notion-review`의 같은 이름 절을 따른다. 이 대화에서 아직 읽지 않았으면 이 스킬 폴더 옆의 `../foodtapa-notion-review/SKILL.md`에서 그 절을 먼저 읽는다.
- 사이트 API 판단 기준은 `../foodtapa-notion-review/references/api.md`를 따른다. 사이트 API는 바뀔 수 있으므로 판단은 사이트 응답, 사이트가 알려 주는 목록, 이 지침 순서로 한다.
- 사이트가 `200`·`201`·`202`가 아닌 응답을 주면 `foodtapa-review-errors` 스킬을 불러 따른다. 부를 수 없으면 `../foodtapa-review-errors/SKILL.md`를 읽는다.
- 아래 명령의 `$api`는 메인 스킬 "전송 방법"과 같이 정한다.

  ```sh
  set -a; . ./foodtapa-api.env; set +a
  api="$FOODTAPA_SITE/wp-json/fdt/v1/workflows/external-reviews"
  ```

## 튜토리얼 전용 규칙

- **샘플은 실제 원고가 아니다.** 원자료 ID·원고 ID·분류는 시험용 가상값이다. 사이트에 공개되면 안 된다.
- **노션 대신 샘플 파일을 읽는다.** 메인 스킬의 "샘플 파일을 노션 대신 직접 읽어 보내지 않는다"는 이 튜토리얼에만 예외다. 그 밖의 규칙(원고 문장을 바꾸지 않음, 전송 전 확인, 비밀값을 다루지 않음)은 그대로 지킨다.
- **발행 연습은 임시저장(`draft`)으로만 한다.** 샘플의 `예약 일시`는 쓰지 않는다. 예약(`future`)이나 지금 공개(`publish`)로 보내지 않는다. 사람이 공개를 원해도 튜토리얼 안에서는 하지 않고 실제 원고로 하라고 안내한다.
- 단계마다 답변 맨 위에 `### 🧭 튜토리얼 n/8 · 단계 이름`을 단다. 끝에는 다음 단계로 가려면 무엇을 답하면 되는지 한 줄로 알린다. 사람이 그만하자고 하면 8단계 정리 안내만 하고 멈춘다.

## 진행 순서

| 단계 | 할 일 | 쓰는 스킬 |
| --- | --- | --- |
| 1. 시작 안내 | 아래 "시작 안내"를 보여 주고 **시작** 답을 받는다 | |
| 2. 설치 확인 | 이름이 `foodtapa-`로 시작하는 스킬이 모두 보이는지 확인한다. 빠진 스킬이 있으면 `foodtapa-install-check`의 안내대로 알리고 멈춘다 | `foodtapa-install-check` |
| 3. 접속 설정 | 접속 정보 파일, 사이트 연결, 사이트 AI 키를 확인한다. 이미 설정돼 있으면 확인만 하고 넘어간다. AI 키가 `미등록`이면 등록 안내를 하고 멈춘다 | `foodtapa-setup` |
| 4. 샘플 원고 보기 | 아래 "샘플 원고 보기" | |
| 5. 원고 점검 | 샘플의 관리 정보로 메인 스킬 "필수 정보 점검"을 하고 결과 표를 보여 준다. 실제로는 `foodtapa-notion-fill`이 노션 원고를 이렇게 점검한다고 알린다 | |
| 6. 검수 보내기 | 메인 스킬 진행 순서 2~6단계를 그대로 한다. 페이지 대신 샘플 파일을 나누고, `notion_url`은 넣지 않는다. 확인 표를 보여 주고 **전송** 답을 받은 뒤 보내고 결과를 조회한다 | `foodtapa-notion-review` |
| 7. 결과에 따라 | 아래 "결과에 따라" | `foodtapa-review-override`, `foodtapa-review-publish` |
| 8. 정리와 다음 단계 | 아래 "정리와 다음 단계" | |

### 시작 안내

아래 표를 보여 주고 **시작** 답을 받는다.

| 항목 | 내용 |
| --- | --- |
| 하는 일 | 샘플 원고를 사이트 검수로 보내고, 결과를 보고, 임시저장 글로 등록해 본다 |
| 걸리는 시간 | 10분 안팎(검수 결과를 기다리는 1~2분 포함) |
| 준비물 | 사이트 관리자 계정. 노션은 필요 없다 |
| 사이트에 남는 것 | 검수 목록의 접수 기록 1건, 임시저장 글 1개(8단계에서 지우는 방법을 안내) |
| 비용 | 사이트 AI 검수 1회 안팎의 사용료(사이트에 등록된 AI 키) |

### 샘플 원고 보기

1. `../foodtapa-notion-review/samples/01-pass-LEARN-9001.md`를 읽는다.
2. 관리 정보, 제목, 본문 앞부분, 댓글 구조(댓글·대댓글)를 짧게 보여 준다. 실제 노션 원고도 이처럼 관리 정보와 본문, 들여쓴 댓글로 적는다고 알린다. 관리 정보는 DB 칸으로 적어도 되고 이름이 달라도 된다고 덧붙인다.
3. `예약 일시`는 실제 원고에서 예약 발행에 쓰는 값이며 튜토리얼에서는 쓰지 않는다고 알린다.

### 결과에 따라

- **통과**: 발행 연습으로 간다. `foodtapa-review-publish`의 확인 표를 보여 주되 발행 방식을 "임시저장(튜토리얼 연습)"으로 적는다. **발행** 답을 받으면 `{"status":"draft"}`로 보낸다. 응답의 글 편집 주소를 보여 주고, 사이트 관리자로 로그인한 뒤 열면 글과 분류가 들어간 모습을 볼 수 있다고 알린다. 댓글은 글이 공개될 때 등록되므로 임시저장 상태에서는 보이지 않는다고 덧붙인다.
- **수정 필요·근거 부족**: 지적 내용을 쉬운 말로 풀어 준다. 실제로는 노션 원고를 고쳐 새 버전으로 다시 보내거나(`foodtapa-notion-revise`), 판정이 맞지 않으면 사유와 함께 관리자 허용(`foodtapa-review-override`)을 한다고 알린다. 노션이 없는 튜토리얼에서는 관리자 허용으로 연습한다. 사유는 사람에게 받는다(예: "튜토리얼 연습"). 허용되면 위 "통과"로 이어 간다.
- **오류**: `foodtapa-review-errors`대로 원인을 찾는다. 사이트 AI 키가 없으면 3단계 AI 키 등록으로 돌아간다.
- AI 판정은 같은 원고도 매번 같지 않을 수 있다고 한 번 알린다. 통과 예시 샘플도 근거 부족이 나올 수 있다.

### 정리와 다음 단계

1. 남은 것을 알려 준다.
   - 사이트의 임시저장 글: 글 편집 화면에서 **휴지통으로 이동**을 누르면 지워진다. 공개되지 않은 글이라 그대로 두어도 사이트 방문자에게는 보이지 않는다.
   - 사이트 검수 목록의 접수 기록: 관리자 화면 **자동화 → 외부 원고 검수 → 검수 목록**에 남는다. 연습 기록으로 두어도 된다.
2. 실제 원고로 쓰려면 노션 연결이 필요하다고 알린다. 연결 방법은 메인 스킬 "노션 연결"을 따른다(설정 → 커넥터에서 Notion 연결, Code 탭에서 못 읽으면 `/mcp` 인증).
3. 실제 원고로 쓸 때의 요청 문장을 표로 보여 준다.

   | 하고 싶은 일 | 요청 |
   | --- | --- |
   | 원고 보내기 | 노션 원고 검수 보내 주세요. 링크: https://… |
   | 보내기 전 점검 | 노션 원고 점검해 주세요. 링크: https://… |
   | 결과 확인 | 검수 결과 확인해 주세요. 링크: https://… |
   | 고쳐서 다시 보내기 | 노션 원고 수정 반영해 주세요. 링크: https://… |
   | 판정 허용 | 관리자 허용해 주세요. 링크: https://… |
   | 예약 발행 | 발행해 주세요. 링크: https://… (노션 원고에 예약 일시를 적어 둔다) |

4. 답변 맨 위에 **🎓 튜토리얼 완료**를 단다. 중간에 멈췄으면 **⏸️ 튜토리얼 멈춤 · n단계**로 바꾸고, 같은 요청을 다시 보내면 이어서 할 수 있다고 알린다.

## 더 해 보기 (사람이 원할 때만)

- **노션으로 해 보기**: 노션이 연결돼 있으면 메인 스킬 "샘플 원고"대로 샘플을 노션 새 페이지로 만들고, `foodtapa-notion-fill`로 점검한 뒤 그 링크로 검수 보내기를 한다. 노션 페이지에는 `예약 일시` 줄을 옮기지 않고 발행 연습은 임시저장으로만 한다.
- **수정 반영 연습**: 노션이 연결돼 있을 때만 한다. `02-revise-LEARN-9003.md`를 노션 페이지로 만들어 보낸다. 본문이 350자에 못 미쳐 수정 필요가 나오면 `foodtapa-notion-revise`로 노션을 고쳐 다시 보낸다. 이 연습은 그 샘플 페이지의 문장을 바꾼다.

# 발행·예약

## 시작 전에

- 이 스킬은 음처기넷 플러그인의 세부 스킬이다. 작업 폴더와 접속 정보, 보낼 사이트, 지켜야 할 규칙, 실행 환경, 전송 방법(인증)은 메인 스킬 `foodtapa-notion-review`의 같은 이름 절을 따른다. 이 대화에서 아직 읽지 않았으면 이 스킬 폴더 옆의 `../foodtapa-notion-review/SKILL.md`에서 그 절을 먼저 읽는다.
- 사이트 API 판단 기준은 `../foodtapa-notion-review/references/api.md`를 따른다. 사이트 API는 바뀔 수 있으므로 판단은 사이트 응답, 사이트가 알려 주는 목록, 이 지침 순서로 한다.
- 사이트가 `200`·`201`·`202`가 아닌 응답을 주면 `foodtapa-review-errors` 스킬을 불러 따른다. 부를 수 없으면 `../foodtapa-review-errors/SKILL.md`를 읽는다.
- 아래 명령의 `$api`는 메인 스킬 "전송 방법"과 같이 정한다.

  ```sh
  set -a; . ./foodtapa-api.env; set +a
  api="$FOODTAPA_SITE/wp-json/fdt/v1/workflows/external-reviews"
  ```
- 메인 스킬에서 이어 온 것이 아니면 노션 링크를 받아 그 페이지 하나에서 원고 ID와 예약 일시를 읽는다. 링크가 없으면 그것 하나만 묻는다.
- 접수 번호는 `foodtapa-review-status` 스킬의 "최신 접수 찾기"로 찾는다. 최신 접수가 `passed`가 아니면 발행하지 않고 현재 상태만 알린다.
- 임시저장(`draft`)·검토 대기(`pending`)로 등록해 달라고 하면 같은 요청에 그 `status`를 넣고 `date`는 넣지 않는다. 허용값은 `../foodtapa-notion-review/references/api.md`의 "발행"과 사이트 라우트 목록을 따른다.

## AI에게: 발행·예약

이 요청이 사이트의 발행 승인이다. 사람이 **발행**이라고 답하기 전에는 보내지 않는다.

1. 페이지의 예약 일시를 한국 시간으로 읽어 `2026-12-01T09:00:00+09:00` 형식으로 바꾼다. 날짜만 있고 시각이 없거나 이미 지난 시각이면 짐작하지 않고 묻는다.
2. 아래 표를 보여 주고 **발행** 답을 받는다.

   | 항목 | 값 |
   | --- | --- |
   | 원고 ID / 버전 | |
   | 제목 | |
   | 발행 방식 | 예약 (한국 시간 날짜·시각) |
   | 함께 공개될 댓글 수 | 글이 공개될 때 함께 등록됩니다 |

3. 같은 인증 방식으로 `"$api/{접수 id}/publish"`에 `{"status":"future","date":"2026-12-01T09:00:00+09:00"}`를 POST로 보낸다. 사람이 지금 바로 공개하라고 하면 `{"status":"publish"}`로 보낸다.
4. 응답의 `status`가 `future`인지, `date_gmt`가 요청 시각과 같은지(UTC라 한국 시간에서 9시간 뺀 값) 확인하고 `edit_url`과 함께 보고한다. `comments_skipped`가 1 이상이면 관리자가 보류·폐기한 댓글이 빠졌다고 알린다.

- 예약 시각을 바꿀 때도 같은 요청을 새 시각으로 다시 보낸다. 같은 글의 예약 시각만 바뀐다. `date`에는 반드시 `+09:00`을 붙인다.
- `409`에 "운영자가 보류한 글입니다"가 오면 반복하지 말고 사이트 관리자에게 보류 해제를 요청하라고 알린다.
- `500`에 `fdtw_external_image_attach`가 오면 글은 임시저장으로 돌아가 있다. 같은 요청을 한 번 다시 보내고, 또 실패하면 멈추고 알린다.
- 그 밖의 `409`·`422`는 응답의 `message`와 `data.reason`을 그대로 알리고 반복하지 않는다.

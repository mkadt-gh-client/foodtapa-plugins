# 노션 원고 정보 채우기

검수 API에 필요한 값은 정해져 있지만 노션에 적는 형태는 고객사마다 다르다. 원고 DB의 칸일 수도, 본문 위쪽 목록일 수도, 칸 이름이 다를 수도 있다. 이 스킬은 형태를 바꾸라고 하지 않고, 그 원고가 쓰는 형태 안에서 필요한 값을 찾고 채운다.

## 시작 전에

- 이 스킬은 푸드타파 플러그인의 세부 스킬이다. 작업 폴더와 접속 정보, 보낼 사이트, 지켜야 할 규칙, 실행 환경, 전송 방법(인증)은 메인 스킬 `foodtapa-notion-review`의 같은 이름 절을 따른다. 이 대화에서 아직 읽지 않았으면 이 스킬 폴더 옆의 `../foodtapa-notion-review/SKILL.md`에서 그 절을 먼저 읽는다.
- 사이트 API 판단 기준은 `../foodtapa-notion-review/references/api.md`를 따른다. 사이트 API는 바뀔 수 있으므로 판단은 사이트 응답, 사이트가 알려 주는 목록, 이 지침 순서로 한다.
- 사이트가 `200`·`201`·`202`가 아닌 응답을 주면 `foodtapa-review-errors` 스킬을 불러 따른다. 부를 수 없으면 `../foodtapa-review-errors/SKILL.md`를 읽는다.
- 아래 명령의 `$api`는 메인 스킬 "전송 방법"과 같이 정한다.

  ```sh
  set -a; . ./foodtapa-api.env; set +a
  api="$FOODTAPA_SITE/wp-json/fdt/v1/workflows/external-reviews"
  ```
- 한 번에 원고 한 편만 다룬다. 노션 링크가 요청에 없으면 그것 하나만 묻는다.
- 원고 문장(제목·본문·댓글)은 바꾸지 않는다. 이 스킬이 노션에 적는 것은 관리 정보뿐이다. 제목에 목표 키워드가 없는 것처럼 문장을 고쳐야 하는 문제는 알리기만 하고 사람이 고치게 한다.

## 1. 읽기

1. 노션 커넥터로 페이지 속성(DB의 칸)과 본문을 하위 블록까지 읽는다. 커넥터가 없으면 메인 스킬 "실행 환경"의 노션 토큰 방법을 쓴다.
2. 메인 스킬의 "필요한 값 찾기" 표의 **뜻**으로 값마다 어디에 적혀 있는지 찾는다. 칸 이름이 표의 예시와 달라도 뜻이 같으면 그 칸이다. 뜻이 애매한 칸은 대응을 짐작하지 말고 3단계에서 함께 묻는다.
3. 이 원고가 값을 적는 **형태**를 정리한다.
   - DB 칸: 이 원고가 원고 DB의 한 행이고 관리 정보가 칸에 있다.
   - 본문 목록: 본문 위쪽에 `- 원자료 ID: …` 같은 목록이나 표로 있다.
   - 섞임: 일부는 칸, 일부는 본문에 있다.
   - 없음: 관리 정보를 적은 곳이 없다.
4. 분류 대조를 위해 사이트에 등록된 분류 이름을 `../foodtapa-notion-review/references/api.md`의 "판단 기준" 5로 조회한다.

## 2. 점검 결과 보여 주기

필요한 값마다 아래 표로 보여 준다. 모두 충족이면 표 아래에 "검수에 필요한 값이 모두 있습니다"라고 쓰고 5단계로 간다.

| 필요한 값 | 지금 값 | 읽은 곳 | 상태 | 왜 필요한가 |
| --- | --- | --- | --- | --- |

- 상태는 ✅ 충족, ❌ 빠짐, ⚠️ 형식 틀림, ➖ 해당 없음, ❓ 대응 확인 필요로 적는다.
- **왜 필요한가** 칸에는 아래를 짧게 옮긴다.

| 필요한 값 | 왜 필요한가 | 충족 기준 |
| --- | --- | --- |
| 원자료 ID | 같은 바탕 자료에서 나온 원고를 묶는다 | 있음. 영문·숫자로 시작하고 영문·숫자와 `_ . : -`만 |
| 원고 ID | 원고 한 편을 구분한다. 고쳐 다시 보내도 같아야 새 버전으로 이어진다 | 있음. 형식은 원자료 ID와 같음 |
| 활용 범위 | 검수 AI가 이 원고가 다루는 질문을 알아야 판정한다 | 있음 |
| 유형 | 분량·키워드 기준이 유형에 따라 다르다 | 검색형·생활형·일상형 중 하나 |
| 목표 키워드 | 검색형은 제목에 키워드가 정확히 한 번 있어야 통과한다 | 검색형이면 있음. 있으면 제목에 정확히 한 번 |
| 글 종류 | 사이트의 어느 게시판(질문·후기·정보글)에 올라갈지 정한다 | 질문·후기·정보글 중 하나. 정보글이면 사진 없음과 소제목 3개 |
| 분류 | 사이트에서 제품군·브랜드 등으로 찾을 수 있게 한다 | 비어도 된다. 적었으면 사이트에 등록된 이름과 글자까지 같음 |
| 근거 | 제품·정책·수리 결과를 단정한 문장을 검수 AI가 확인한다 | 선택. 단정한 문장이 있는데 비었으면 "근거 부족"이 나올 수 있다고 알림 |
| 예약 일시 | 검수 통과 뒤 예약 발행할 때 쓴다 | 발행까지 맡길 때만 필요. 날짜와 시각이 모두 있고 지금보다 뒤 |

- 본문이 350자 미만이거나 제목에 목표 키워드가 정확히 한 번이 아니면 표 아래에 경고로 덧붙인다. 원고 문장이라 이 스킬은 고치지 않는다.

## 3. 값 정하기

빠지거나 틀린 값을 한 번에 정리해 보여 주고 답을 받는다. 하나씩 따로 묻지 않는다.

| 필요한 값 | 누가 정하나 | 할 일 |
| --- | --- | --- |
| 원자료 ID, 원고 ID | 사람 | 값을 묻는다. 형식만 틀리면(예: `LEARN 0654`) 형식만 고친 안(`LEARN-0654`)을 보여 주고 확인받는다. 새 번호를 만들어 주지 않는다 |
| 활용 범위, 유형, 목표 키워드 | 사람 | 값을 묻는다. 유형은 세 가지 중 고르게 한다 |
| 글 종류 | AI 제안 가능 | 본문이 묻는 글이면 질문, 써 본 경험이면 후기, 정리·안내 글이면 정보글로 제안하고 그렇게 본 문장을 함께 보여 준다 |
| 분류 | AI 제안 가능 | 사이트 등록 이름 가운데 본문·제목에 실제로 나오는 것만 제안하고 나온 문장을 함께 보여 준다. 등록되지 않은 이름이 필요하면 사이트 관리자가 먼저 등록해야 한다고 알린다 |
| 근거 | 사람 | 정제된 근거가 있는지 묻는다. 없으면 빈 값으로 둔다. 근거를 지어내지 않는다 |
| 예약 일시 | 사람 | 날짜와 시각(한국 시간)을 묻는다 |
| ❓ 대응 확인 | 사람 | "이 칸 `번호`가 원고 ID가 맞나요?"처럼 묻는다 |

- AI가 제안한 값에는 "(AI 제안)"을 붙인다. 사람이 받아들인 값만 쓴다.
- 이 값들은 비밀값이 아니므로 대화창으로 받아도 된다. 다만 개인정보(실명·연락처)는 받지 않는다.

## 4. 노션에 적기

1. 적을 값을 아래 표로 보여 주고 **적용** 답을 받는다.

   | 필요한 값 | 적을 값 | 적을 곳 |
   | --- | --- | --- |

2. **적을 곳은 그 원고가 이미 쓰는 형태를 따른다.**
   - DB 칸 형태: 그 값의 칸이 있으면 그 칸에 적는다. 칸이 없으면 새 칸을 만들지 말고 본문 관리 정보 목록에 적을지 사람에게 묻는다. DB에 칸을 더하는 것은 다른 원고 모두에 영향을 주므로 사람이 정한다.
   - 본문 목록 형태: 기존 목록의 표기(예: `- 원자료 ID: S-9001`)와 같은 모양으로 그 목록에 한 줄 더하거나 고친다.
   - 관리 정보가 없는 원고: 본문 맨 위에 "관리 정보" 목록을 만들어 적을지, DB 칸으로 관리할지 사람에게 묻는다. 고객사가 정한 형태가 있으면 그것을 따른다.
3. 이미 충족된 값은 사람이 바꾸라고 하지 않는 한 덮어쓰지 않는다.
4. 노션 커넥터로 적는다. 커넥터가 없으면 `NOTION_TOKEN`으로 노션 API를 쓴다. 속성은 `PATCH https://api.notion.com/v1/pages/{페이지 ID}`, 본문 줄은 `PATCH https://api.notion.com/v1/blocks/{블록 ID}` 또는 `PATCH https://api.notion.com/v1/blocks/{부모 ID}/children`이다. 선택형 칸은 기존 선택지 이름을 그대로 쓰고, 날짜 칸은 한국 시간대(`+09:00`)로 시각까지 적는다.

## 5. 다시 점검하고 마무리

1. 페이지를 다시 읽어 2단계 점검을 한 번 더 한다. 적은 값이 실제로 들어갔는지 본다.
2. 답변 맨 위에 **✅ 원고 정보 채우기 완료** 또는 **⚠️ 원고 정보 채우기 미완료**를 단다.
3. 모두 충족이면 "이제 **노션 원고 검수 보내 주세요. 링크: …**로 보낼 수 있습니다"라고 안내한다. 메인 스킬의 검수 보내기 도중 넘어왔으면 바로 메인 스킬 진행 순서 1단계로 돌아가 이어 간다.
4. 같은 형태의 다른 원고도 채워야 하면, 이번에 확인한 칸 대응과 적는 형태를 다음 원고에도 그대로 쓴다고 알린다. 원고는 한 편씩 진행한다.
